# Material de referência

Não entra no painel montado; serve de fonte para a implementação.

- `toliman-paineis/` — design system Tóliman Painéis (tokens.json, bundle.css, README) e os logos brancos
  (para fundo `navy`) tirados do Radar de Fretes Tóliman. O logo colorido do design system não pôde ser
  baixado; o painel usa os brancos sobre o topo azul-marinho.
- `radar-fretes/gravacao-pasta.js` — trecho do Radar de Fretes Tóliman com a gravação na pasta compartilhada
  (trava por `salvoEm`, juntar e salvar, backups, salvamento automático).
